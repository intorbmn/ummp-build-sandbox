# Phase 11 - User Interface (Tauri) Implementation Plan

> Native execution (user's choice): `superpowers:executing-plans` with `superpowers:test-driven-development`.
> Ledger: `.superpowers/sdd/phase11-ui/progress.md` (every deviation as `Ruling: <decision> - <why> - <cost if wrong>`).

**Goal:** A Tauri desktop app (Svelte front-end) whose every action is a tested application service in `core/src/app/`; the CLI uses the same services.

**Architecture:** `ui/src` (Svelte, `invoke` only in `lib/api.ts`) -> `ui/src-tauri` (separate Cargo workspace) -> `core/src/app/` -> existing engines.

**Spec:** `docs/superpowers/specs/2026-11-20-phase11-ui-design.md`. Scope source: `docs/guides/phase-11-ui.md`.

## Global Constraints
- The four commands pass before every commit (baseline 213 tests on master).
- `unsafe_code = "forbid"`; clippy pedantic + nursery as errors. No async runtime and no HTTP in `core`.
- Files change only through `MigrationEngine` after a checkpoint, or by writing into a new output folder (ADR 0005/0006).
- In-place apply needs `reviewed = true`, otherwise `AppError::Refused`. High risk blocks pack migrate and local build without an explicit acknowledgment.
- Keys and tokens are held in the `Secret` type: not `Serialize`, prints `***`; no command returns a stored value; nothing sensitive in `settings.json`, logs or events.
- Every path from the UI is validated in the services (exists, right kind, `resolve_within` when combined).
- Synthetic names in fixtures and docs (`DemoWidget`). Next ADR number is 0014.

## Review Focus
- A path that does not exist, is a file where a folder is expected, or is an empty folder: clear `Input` error, no panic.
- Cancel while a job waits on an approval, and cancel twice: job ends `Cancelled`, no file written.
- App closed while a job runs: next `open` marks it `Failed` ("interrupted"), never "Running" forever.
- 10 000-line log and 300-mod pack: <= 20 `job.log` events/s per job; the full log is in `JobDb`.
- Output folder not empty or inside the source: `port` refuses; source untouched.
- Vietnamese strings are longer: no clipped labels on Plan & Diff.
