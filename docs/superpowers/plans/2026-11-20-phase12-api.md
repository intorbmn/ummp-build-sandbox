## Global constraints

- All application behavior goes through `core/src/app/AppServices` (ADR 0004). CLI, desktop, REST and MCP are adapters only.
- Core remains synchronous. Tokio is restricted to `server/`; use `spawn_blocking` at transport boundaries.
- `unsafe_code = "forbid"`; preserve workspace lint policy.
- File changes go through existing migration/checkpoint services or a new output directory (ADR 0005/0006).
- Every untrusted path is checked against allowed roots and uses `resolve_within` for joined paths.
- Never log, serialize, display, return or pass raw secrets in arguments/events/settings/JSON/REST/MCP/plugin output.
- Tests use temporary directories and synthetic keys. No live provider calls in CI.
- Keep each change small; add the failing test first, implement the minimum, run focused tests, then full checks.
- Preserve existing branch commits. No reset, rebase, force-push or history rewrite.
- Existing partial 12.A work is reviewed and completed, not recreated.

## PR 1 — Milestone 12.0 + 12.A

### 12.0-A — Core credential contract and file store

**Files**
- Add `core/src/app/credentials.rs`.
- Update `core/src/app/mod.rs` to expose the module and credential error conversions as needed.
- Update core tests and fixtures only where required.

**Implementation**
1. Add `AiProviderKind` with lowercase Serde representation.
2. Define `AiKeyStore: Send + Sync` with minimal `get`, `set`, `delete`, `masked` operations. Keep callers independent of the backing format/path.
3. Add `FileKeyStore` and a private versioned `CredentialsFile` schema:
   - `schema: 1`
   - Anthropic key
   - OpenAI-compatible key
   - optional OpenAI-compatible base URL
4. Add `default_data_dir()` and `UMMP_DATA_DIR` override. Match the Tauri app identifier and OS conventions exactly.
5. Add `resolve_ai_key(data_dir, provider)` plus a testable internal resolver that accepts an explicit environment value; do not mutate process environment in parallel tests.
6. Validate keys (trim, non-empty, <=512 characters, no control characters); return a non-fatal warning for an Anthropic key without `sk-ant-`.
7. Implement masking and idempotent deletion.
8. Use same-directory temporary file, restrictive Unix permissions before writing, flush/sync, and atomic replacement. Preserve the other provider key and base URL.
9. Handle missing file, corrupt JSON, unsupported schema and I/O failure without panic or secret-bearing error text.
10. Add a typed credential error and map it into `AppError` without including secret values.

**Test-first acceptance**
- [ ] Round trip one provider.
- [ ] Updating one provider preserves the other provider and base URL.
- [ ] Environment variable overrides file value; absent env falls back to file.
- [ ] Raw key absent from `Debug`, settings serialization, event payloads and job serialization.
- [ ] Masking exact behavior for normal and short keys.
- [ ] Empty, overlong and control-character values rejected.
- [ ] Anthropic prefix warning is present but key is accepted.
- [ ] Unix file permissions are 0600.
- [ ] Failed atomic replacement leaves previous valid credentials intact.
- [ ] Corrupt JSON and unsupported schema return safe typed errors.
- [ ] Delete missing provider is idempotent and preserves the other provider.
- [ ] `UMMP_DATA_DIR` override and OS default paths tested without mutating global env unsafely.
- [ ] Mutation-check starred tests: round-trip/preserve-other-provider and environment override. Record mutation, expected failure and result in phase evidence.
